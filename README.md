# 🚖 Uber Trip Analysis Dashboard

A comprehensive Power BI dashboard analyzing Uber trip data to uncover booking patterns, revenue trends, trip efficiency, and time-based demand, helping stakeholders make informed, data-driven decisions.

## 📊 Dashboards Overview

### 1. Overview Analysis
Gain high-level insights into the performance of Uber trips.

**Key Metrics:**
- Total Bookings
- Total Booking Value
- Average Booking Value
- Total Trip Distance
- Average Trip Distance
- Average Trip Time

**Key Features:**
- Dynamic Measure Selector (e.g., Total Bookings, Revenue)
- Filters by Payment Type and Trip Type
- Location Analysis (Pickup/Drop-off Points, Farthest Trips)
- Grid View for Vehicle Type KPIs

### 2. Time Analysis
Understand trip trends across time intervals for smarter scheduling and resource allocation.

**Visualizations:**
- Bookings by Pickup Time (10-min intervals)
- Bookings by Day of Week
- Hourly Heatmap (Hour × Day Grid)

### 3. Details Tab
Explore detailed trip-level records with drill-through functionality.

**Features:**
- Grid Table with essential fields
- Drill-through from charts and visuals
- Bookmark toggle to view full data


## 🛠️ Implementation Highlights

- Dynamic Titles based on selected metrics
- Slicers for City, Date, and Time
- Conditional formatting for insights
- Bookmarks: "View Full Data", "Data Details", "Reset Filters"
- Download raw data via Power Automate or built-in export

## 📁 Project Files

## 🚀 How to Use

1. Clone or download the repository.
2. Open `UberTripAnalysis.pbix` in Power BI Desktop.
3. Explore and interact with the visualizations.
4. Modify slicers and selectors to tailor the insights.
